What I'm learning

HTML, CSS & JavaScript

These three tools work together to turn ideas into interactive websites.

01

HTML gives a page structure

Headings, paragraphs, links, images, and buttons are described with HTML elements, so a browser can understand what the page contains.

02

CSS sets the style

CSS controls colors, spacing, layout, and effects such as the hover transitions on this page.

03

JavaScript adds interaction

JavaScript can respond to clicks and keyboard input, update scores, and make games like the fruity match game.

04

Small experiments teach a lot

Changing one rule, testing it in a browser, and noticing what happened is a great way to learn how websites work.
